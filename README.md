# Automotive-Claims-Performance-Dashboard---MIS-Report

# Summary 

  This MIS Report provides a consolidate view of automotive claims, customer distribution, dealer performance
  and part level activity. It supports management monitoring of claims trends and operational performance using 
  Excel based Reporting.

# Key Visuals & Analysis Included
 
  1) Top 3 dealers based on Customer Count.
  2) Top 3 Customers by total Claim Amount.
  3) Quarter wise Claim Amount trend.
  4) Customer distribution by State and City.
  5) Frequency of Failed Parts by Part ID.

# Tools
 
  Advance Excel, Pivot Tables, Visuals.
